# Лабораторна №8 — PowerFit

Ванільна JavaScript-версія з каталогом тренувань, пошуком і фільтром із попередньої лабораторної та окремим списком власних тренувань.

## Запуск

Відкрийте папку `C:\laba` у VS Code і запустіть `index.html` через Live Server (не подвійним кліком). Для збереження записів використовуйте стабільну адресу localhost.

## Функції №8

- Форма власного тренування: назва (3–80 символів), категорія та опис (10–500 символів).
- Створення запису без перезавантаження, з унікальним UUID; видалення за id.
- Безпечне відображення тексту через `textContent` і порожній стан.
- Відновлення та збереження власного списку під одним ключем localStorage; перевірка структури й обробка помилок сховища.

Код знаходиться у `js/userItems.js` та `js/storage.js`; форма — у секції `#my-workouts` файлу `index.html`. Ініціалізація відбувається незалежно від завантаження каталогу в `js/main.js`.
